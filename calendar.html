입력칸 안에서 글자를 선택한 뒤 굵게·밑줄·색상·강조를 적용하세요. 글자 크기는 선택한 입력칸 전체에 적용됩니다. 우측의 월별 메모에도 동일한 도구를 사용할 수 있습니다.

메모 모아보기 탭에서 모든 월별·반복·업무별 메모를 보고 편집할 수 있습니다. 각 업무 옆 ▤ 버튼은 개별 메모를 작성합니다. 토·일요일은 평일 너비의 약 38%로 표시되며 주말 넓게 버튼으로 원래 비율로 전환할 수 있습니다. 우측에는 매달 할 일, 중요사항, 자유 메모가 있습니다. 메모 칸을 더 만들거나 제목을 바꿀 수 있습니다. ‘매달 반복’은 해당 메모 내용을 모든 달에 보여 줍니다. 반복 메모를 수정하면 모든 달에서 함께 바뀝니다.

뒤로가기·앞으로가기 버튼은 편집 내용의 실행 취소·다시 실행입니다. Ctrl+Z / Ctrl+Y도 사용할 수 있고, 새로 파일을 열면 실행 취소 기록은 초기화됩니다. 메모와 달력 사이의 ⋮ 손잡이를 좌우로 끌어 메모 너비를 조절하세요. 현재 PC의 브라우저에 자동 저장됩니다. 서버 저장이나 여러 PC 간 자동 동기화는 제공하지 않습니다. 전체 백업으로 JSON 파일을 보관하고 다른 PC에서 불러오세요. 인쇄 / PDF는 현재 달을 출력합니다.
